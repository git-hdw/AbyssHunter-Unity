# 深渊猎手 v0.2.0：深渊与微光

发布日期：2026-10-20。平台：Windows x64。引擎：Unity 6.3 LTS（6000.3.23f1 / URP）。

演示视频：[《深渊猎手》v0.2.0 实机演示（MP4，约 39.2 MiB）](https://github.com/git-hdw/AbyssHunter-Unity/releases/download/v0.2.0/AbyssHunter-Demo-v0.2.0.mp4)。视频作为本版本 Release 附件提供。

本次更新让《深渊猎手》从机器人外观的展示基线，转为兜帽猎手深入沉没遗迹、守护微光并带回核心的主题版本。沿用已有普通敌人与重锤守卫的战斗体系，重点更新角色、环境、镜头与归途表现，并修复独立包中的碎片计数问题。

正式 Windows x64 包构建成功：0 错误、0 警告，构建耗时约 22 秒。正式包未启用 Development Build，不包含自动回归测试驱动。

## 相比上一版

- 主角由机器人替换为持剑的兜帽猎手；普通敌人与重击敌人分别采用骷髅斥候和重锤守卫。保留已有 Animator、攻击事件、碰撞与对象池规则。
- 增加随身护火灯：局部暖光、呼吸与摆动、受击收缩后恢复、死亡熄灭，取回核心后火光稳定。
- 三处遗迹拥有不同装饰：入口营地、庭院倒像与锁链、祭坛晶簇与悬石；平台下方增加沉没建筑、层雾及坠落碎屑。
- 调整石材、青铜、湿痕、冷色轮廓光和暗紫侵蚀，保持橙色重击预警及青色反击提示清晰。
- 加入开场拉远、区域镜头变化和建筑遮挡淡化；核心回收、沿途亮灯、归途信标形成连续表现。
- 新增桥下风声、锁链、祭坛、落石及随身火焰空间音效，信标点亮后降低环境底音。
- 修复中文弹层标题与统计数字裁切、暂停时开场镜头不动、载入耗时跳过动画，以及主菜单淡入露出天空盒。
- 合并静态环境几何，降低绘制批次；新增环境验证工具和按版本号输出的 Windows 发布构建入口。
- 物品计数、堆叠及扣除改用稳定 Item ID，修复独立包中已拾取六枚碎片却被信标判定为零枚的问题。

## 下载与运行

在 [GitHub Release v0.2.0](https://github.com/git-hdw/AbyssHunter-Unity/releases/tag/v0.2.0) 下载 `AbyssHunter-Windows-v0.2.0.zip`，完整解压后运行 `AbyssHunter.exe`。请保留同目录下的数据文件夹、运行库和许可文件，无须安装 Unity。发布附件同时提供 SHA-256 校验文件。

WASD 移动，鼠标左键攻击，空格闪避，I 背包，Esc 暂停。清除三处遭遇后按 E 取回核心，返回入口投入四枚碎片点亮信标，再按 E 撤离。结算页 R 重开、M 返回菜单。
