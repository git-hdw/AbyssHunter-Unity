# AbyssHunter v0.3.0

## 版本概述

《深渊猎手》是使用 Unity 6.3 LTS 和 URP 制作的单人俯视角动作冒险 Demo，目标平台为 Windows x64。v0.3.0 把原有的单关追猎扩展为两关连续远征，并加入出战武器选择、烬火法师和按账号区分的本机通关记录。

## 核心玩法

- 选关后点击武器，或按 1、2、3 选择猎剑、重斧、轻弩。猎剑快斩，重斧双手横扫，轻弩从弩口发射受实体掩体阻挡的弩矢。整局锁定武器，重开沿用本局选择。
- WASD 移动，左键攻击，空格闪避。可以点选近战目标，在落锤锁向后闪避，再抓住后摇反击。烬火法师会举杖蓄火并发射火球，可横移避开。战斗提示随存活敌人的组合变化。
- 延续 v0.2.0 的核心循环：接近战区、清除守卫、拾取碎片、按 E 取核、返回入口投入碎片，再按 E 撤离。护火灯随受击、死亡和取核改变，沿途符文逐段点亮。

## 游戏系统

中文菜单、操作说明、战斗 HUD、背包、暂停与结算贯通两关。药水可以在背包内使用，每次远征重新初始化生命和物品。PlayFab 负责邮箱认证，本机按账号保存关卡解锁和最佳成功用时。Windows 版使用系统凭据管理器保存会话票据，恢复登录需要联网。

## 技术与性能

- 玩家使用 CharacterController 和 Input System。近战由动画事件去重结算，重锤按独立阶段时钟结算。敌人通过 NavMesh 寻路，依靠 Addressables 和对象池加载、复用。
- 使用稳定物品 ID 统一场景与资源包中的碎片堆叠、统计和扣除。GamePresentation 统一管理界面、暂停与输入阻断。
- 模块化遗迹使用静态网格合并，遮挡建筑和关键晶簇可独立淡化。持核回程结合导航路径与地面符文提示转向。碰撞检测、路径拐点等高频查询复用缓冲区。

## 已知问题与验证边界

- 正常入口依赖联网认证，现有流程回归使用合成身份。真实注册、恢复邮件投递及跨网络会话恢复仍待实测。
- 解锁与最佳用时仅保存在当前电脑。远征途中没有存档，旧 F5/F9 检查点在远征中停用。
- 部分自动输入回放曾漏触发闪避或结算按钮。完整人工战斗平衡、音效辨识及目标硬件帧率仍待评审。

## v0.4.0 后续方向

优先验证三种武器在混战中的操作与反馈，再试作护火灯与场景机关的交互。在现有两关稳定后规划新关卡和 Boss 原型，逐步验证攻击预警、阶段变化与撤离节奏。
