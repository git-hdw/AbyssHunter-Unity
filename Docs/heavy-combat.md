# 重击敌人与战斗窗口

这版战斗围绕“诱导重击 → 观察锁向 → 闪避或绕侧 → 趁后摇反击”展开。普通敌人保持追击、近战和受击后退，重击敌人承担范围威胁。

## 如何体验

打开 `Assets/Scenes/MainMenu.unity` 或 `Assets/Scenes/SampleScene.unity` 进入 Play。

1. 第一波：两只普通敌人，熟悉移动、攻击和闪避。
2. 第二波：一只重击敌人，单独练习观察前摇与反击。
3. 第三波：一只重击敌人和两只普通敌人，需要先拉开位置，避免在重击范围里连续攻击。

WASD 移动、左键攻击、Space 闪避。闪避会取消尚未结算的攻击；闪避期间的新攻击输入仍可短暂缓存。自动索敌排除死亡目标。

## 默认节奏

| 阶段 | 时长 / 范围 | 行为与提示 |
| --- | --- | --- |
| 追击 | 移速 2.2，距离 2.5 内起手 | 大体型、铜色护甲、重锤，与普通敌人区分 |
| 蓄力 | 0.8 秒 | 前 0.3 秒转向追踪；最后 0.5 秒锁定方向。扇形提示由黄转橙，显示“方向已锁定” |
| 落锤 | 0.12 秒 | 进入阶段时结算一次，前方 110°、半径 3 米，25 点伤害；墙体遮挡有效 |
| 后摇 | 1.1 秒 | 显示“破绽 · 趁机反击”，可以靠近反击 |
| 后摇首次受击 | 额外 0.25 秒 | 接受一次击退，距离为普通击退的 65%；后续攻击仍可造成伤害，但不继续延长或击退 |

重击敌人生命值 150。蓄力与落锤期间受到正常伤害，但不被轻击打断或击退。闪避无敌持续 0.2 秒，冷却 0.8 秒；提前交闪避又停在范围内会被命中。主动离开扇形也可以躲开，无需强制依赖无敌帧。

## 实现入口

- `Assets/_Game/Combat/BruteAttack.asset`：前摇、追踪时长、范围、伤害、后摇等参数。
- `EnemyController`：普通敌人保留原状态；重击增加 Windup、Strike、Recovery。伤害由阶段时钟结算，忽略旧动画事件，避免重复命中。
- `EnemyAnimationController`：复用现有双手攻击动画，将动作采样映射到攻击阶段；死亡、回池后恢复 Animator 状态。
- `HeavyAttackPresentation`：从同一攻击配置生成地面扇形、阶段文字、蓄力/落锤音效与轻微震屏。
- `HeavyEnemy.prefab`：独立 Addressable 预制体及对象池，回池清理攻击、抗打断、击退和提示状态。
- 场景 `WaveSpawner` 的 Encounters：可调整每波普通/重击数量与提示。

当前重锤使用简单几何体，音效为程序合成，属于可替换的表现资源。改模型或攻击动画时要同步调 `animationContact`，确保落锤姿势与伤害时刻吻合。

## 验证和构建

Unity 菜单 `Tools > Abyss Hunter > Verify heavy combat` 运行编辑器内集成检查，完成后自动退出 Play，结果写入 `Logs/heavy-combat-verification.txt`，截图在 `Logs/heavy-combat/`。检查会用临时键鼠设备触发真实攻击/闪避，也会用受控站位、生命和障碍物隔离边界条件；它不是对外演示录像。

覆盖锁向和侧移、站桩单次伤害、无敌帧时机、动画事件防重复、后摇反击和延长上限、墙体遮挡、暂停、死亡中断、同实例回池复用、混合波次及结算。

`Tools > Abyss Hunter > Build portfolio player` 先构建 Addressables，再导出 Windows 包至 `Builds/Portfolio/AbyssHunter.exe`。只打开编辑器的 Asset Database 模式不代表玩家包资源已经更新。
