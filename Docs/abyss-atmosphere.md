# 深渊环境与最后的微光

本轮将三段遗迹改为有冷暖对比、纵深和区域特征的深渊远征。正常打开 `Assets/Scenes/SampleScene.unity` 即可编辑已落地的场景，无须重新运行生成工具。

## 环境与材质

- 入口：遗弃营地、熄灭的篝火、旧灯与倒伏铭碑。
- 庭院：倒伏石像、残破锁链、披布与地面侵蚀纹。
- 祭坛：倾斜巨柱、裂隙晶簇、缓慢浮动旋转的悬石与铜盘。
- 平台下方：分层岩脊、沉没楼层、残柱、沿深度布置的漂移薄雾及低数量坠落碎屑（两侧各最多 12 粒）。
- 石板和建筑使用倒角网格、轻微色差和程序生成的石材细纹；青铜与湿痕采用不同粗糙度。

新增装饰集中在战斗区外围，不增加阻路碰撞体。原有石板碰撞、桥梁、敌人触发点和导航数据继续使用。静态不透明几何按材质及空间区域合并，保留原对象供配置工具重建；动态符文、核心、火焰、薄雾和遮挡淡化构件独立渲染。

## 护火灯与光照

猎手背侧的护火灯挂在角色骨骼下，金属框内部是一簇暖金色火苗。光照范围局限于角色附近。火苗随移动轻摆，受击后短暂收缩，随后恢复；死亡时熄灭并散出余烬。灯没有燃料条，也不会额外改变生命、伤害或闪避规则。

冷色方向光负责建筑轮廓和战斗可读性，局部冷光补出遗迹边缘。侵蚀改用暗紫色，与橙色重击预警、青色反击窗口分开。取得核心后，火种进入护火灯，归途符文和路灯由祭坛向入口依次苏醒；点亮信标时，暖色火焰和照明渐亮。

开场镜头由近向远展示灯与遗迹，断桥与祭坛略微拉远。高大建筑挡在镜头与猎手之间时自动淡化，离开后恢复。普通地面和不可通行边界始终保留。

开场与结算镜头使用独立于游戏暂停的表现时间；表现动画的单帧推进上限为 0.1 秒，避免首次载入或切回编辑器时跳过整段倒计时。固定帧率录制继续使用精确的录制帧间隔。

## 声音

新增两处桥下风声、庭院锁链、祭坛低鸣、间歇落石以及随灯移动的微弱火焰声。声音由项目内代码合成，无额外第三方音频授权。信标点亮后环境底音降低。战斗仍使用原有蓄力、落锤、受击音效。

## 维护与验证

- 环境配置入口：`Tools > 深渊猎手 > 环境 > 应用深渊与微光美术`。它重建本轮环境装饰、护火灯和合批资产，会覆盖这些生成对象的手动修改。
- 环境验证入口：`Tools > 深渊猎手 > 环境 > 验证微光与环境表现`。输出 `Logs/atmosphere-verification.txt`，截图目录 `Logs/atmosphere-review/`。
- 游戏回归继续使用远征、重击和中文界面验证。
- 环境性能采样使用 Unity ProfilerRecorder 主线程记录器，并记录五处镜头的批次、三角形及已分配内存。编辑器采样含编辑器自身及帧等待开销，不等同独立运行包性能。
- 环境阶段完成后已追加 Windows 构建及碎片独立包回归，见下文。

主要实现：`AbyssArtSetup`（场景及合批资产）、`LastLight`（护火灯）、`AbyssAtmosphere`（核心与归途表现）、`AbyssOccluder`（遮挡淡化）、`AbyssSoundscape`（环境音）。薄雾使用项目内 `AbyssHunter/DepthMist` 着色器，不要求额外渲染插件。
